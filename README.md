# SaSeBok
The Rice Cookers project for SASEHack 2026

# Purpose

SASEBook is a application for bringing SASE community and other like minded individuals together

# Project Stack

## SASEBook utilizes Typescript with the React framework, compiled using npm and vite

## Installation and development

### Prerequisites

- [Node.js (version 18 or higher)](https://nodejs.org/en/download)
- [Python 3.14](https://www.python.org/downloads/)
- npm package manager
- Git

#### Clone the Repository

```bash
git clone https://github.com/Totoro51212/SASEBook.git
cd SASEBook
```

#### Install npm Dependencies

```bash
cd frontend
npm install
cd ..
```

#### Run dev build for testing

```
npm install
npm run dev
```
